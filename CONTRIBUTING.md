# CONTRIBUTING

This repo grows by pull request. The bar is low for honesty and high for evidence.

## Adding a glossary pairing

One pairing per PR. Include:

1. The soul term and the systems term, plainly stated
2. The mechanism in one or two sentences, what actually behaves like what, and how
3. A source (link). Primary preferred: the paper, the book passage, the code file
4. A falsifiability tier: checkable, interpretive, or speculative (see METHODS.md)
5. Verification level: page-read or index

A pairing without a mechanism will be asked for one. "Both involve circles" is not a mechanism.

## Proposing a missing tie

Open an issue or PR against MISSING-TIES.md with:

1. The two (or more) nodes that should be connected
2. What the connection would look like concretely
3. Who would need to be in the room

If you ARE one of the nodes, even better. Introduce yourself.

## Corrections

Wrong quote, dead link, misattributed idea, tier too generous, PR it. Corrections are the highest-value contribution this repo accepts.

## Tone

Direct, curious, allergic to hype. No guru voice. No debunking voice either. The glossary is a bridge-building site, not a battlefield.
